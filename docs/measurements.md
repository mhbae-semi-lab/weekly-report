## 2. 보고서 작성 클릭 수

같은 입력으로 "지난주(45주차) 보고를 만든 다음, 이번 주(46주차) 보고를 PPTX 로 내보내기"를 두 버전에서 재생하고, 문서 수준 `click` 이벤트(입력란을 누르는 클릭 포함) · 파일 놓기 · 글자를 입력한 칸 수를 셌다. 내장 브라우저에서 스크립트로 사람이 하는 순서대로 재생했다.

- 입력: 45 · 46주차 커밋 15개 (`@@%h|%ad|%s` + `--name-only`, 두 버전 모두 읽는 형식). 46주차 주제 6개 (README 1개는 제외 처리).
- 사람이 쓰는 메모: `js/sample.js` 의 왜 · 상태 문장.
- 가정: 이어받은 '왜' 메모는 그대로 둔다 (고치면 그만큼 더 입력).

| | v0 (포트폴리오 데모) | 현재 |
|---|---|---|
| 불러오기 | 붙여넣기 탭 · 입력란 · 불러오기 = 클릭 3 | 파일 놓기 1 (지난주 메모 유지, 새 커밋만 합침) |
| 주제 이동 | 클릭 5 | 클릭 5 |
| 메모 입력 | 왜 5 + 상태 5 (지난주 메모 없음) | 왜 3 + 상태 5 (이어진 주제 2개는 '왜' 이어받음) |
| 요약 다시 만들기 | 주제마다 '규칙 기반' 클릭 5 (메모를 바꿔도 요약이 그대로) | 0 (손대지 않은 규칙 요약은 메모를 따라감) |
| 제외 · 내보내기 | 클릭 2 | 클릭 2 |
| **합계** | **클릭 25 · 입력 11칸 (붙여넣기 1 + 메모 10)** | **클릭 15 + 파일 놓기 1 = 16 동작 · 입력 8칸** |

- 현재 버전의 클릭 수에서 파일 저장용 프로그램 클릭(링크 a.click) 1개는 뺐다 (사람이 누른 것이 아님).
- v0 는 내보낼 때 PptxGenJS 를 CDN(cdnjs)에서 받는데, 이 측정 환경에서는 그 스크립트를 불러오지 못해 내보내기에 실패했다. 현재 버전은 저장소 안의 번들을 써서 오프라인에서도 내보낸다.
- v0 는 저장 기능이 없어 새로고침 · 다음 주에 메모를 처음부터 다시 쓴다. 현재 버전은 IndexedDB 에 주차별로 남는다.
