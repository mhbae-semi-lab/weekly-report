개인정보 · 데이터 안내

이 앱은 서버가 없는 정적 웹 앱입니다. 운영자는 사용자의 데이터를 받거나 저장하지 않습니다.

어디에 저장되나요

  • 불러온 커밋, 메모, 요약, 설정, Shadow 기록, 재현 세트, 올린 PPTX 양식은 이 브라우저의 IndexedDB 에만 저장됩니다.
  • 오류 기록도 이 브라우저에만 남고 밖으로 보내지 않습니다 (설정 › 데이터 · 오류에서 보고 지울 수 있음).
  • 화면 밝기 선택만 localStorage 에 저장합니다.
  • Anthropic API 키는 페이지 메모리에만 두고 저장하지 않습니다. 새로고침하면 사라집니다.
  • 설정 › 데이터에서 백업(JSON)을 내보내거나, 모든 데이터를 지울 수 있습니다.

밖으로 나가는 경우 (사용자가 버튼을 누를 때만)

  • LLM 생성: 고른 주제의 주제 이름 · 메모 · 커밋 제목이 사용자 본인 키로 api.anthropic.com 에 직접 전송되거나, 로컬 Ollama 주소로 전송됩니다. 보내기 전에 실제 요청을 미리 보여주고, 메일 · IP · URL · Windows/UNC 경로와 사용자가 지정한 단어는 [M1] 같은 자리표시자로 가립니다. 파일 경로 목록은 보내지 않습니다.
  • GitHub 가져오기: 입력한 저장소 이름 · 기간 · 작성자가 api.github.com 으로 전송됩니다.

그 밖의 분석 도구 · 광고 · 외부 오류 수집은 없습니다. 글꼴과 라이브러리도 이 사이트 안의 파일을 씁니다.

Privacy · data

This is a static web app without a server. The operator never receives or stores your data.

Where data is stored

  • Imported commits, memos, summaries, settings, Shadow records, reproduction sets and an uploaded PPTX template are stored only in this browser's IndexedDB.
  • The error log also stays in this browser and is never sent anywhere (view or clear it in Settings › Data · errors).
  • Only the theme choice is kept in localStorage.
  • Your Anthropic API key is kept only in page memory, never saved, and gone on reload.
  • In Settings › Data you can export a JSON backup or erase everything.

When data leaves the browser (only when you press the button)

  • LLM generation: the topic name, memo and commit subjects of the chosen topics are sent with your own key straight to api.anthropic.com, or to your local Ollama URL. The actual request is shown first; e-mail, IP, URL, Windows/UNC paths and your listed words are masked as [M1]-style placeholders. File path lists are not sent.
  • GitHub fetch: the repository name, dates and author you typed are sent to api.github.com.

There are no analytics, ads or external error reporting. Fonts and libraries are served from this site.
